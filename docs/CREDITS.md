# Credits

The source code in this repository is released under the
[MIT License](../LICENSE). Some of the imagery it ships with is not: 58 of the
photographs used by the seeded demo dataset come from Wikimedia Commons under
Creative Commons terms, and those terms travel with the files.

Every one of them is reproduced here with its author, its source and its
licence, and each file is listed by the name it carries in the tree.

## What this means if you reuse the project

**The code is MIT.** Take it, change it, ship it, under the terms in `LICENSE`.

**The photographs listed below are not MIT, and MIT cannot relicense them.**
All of them have been converted to WebP and resized, which makes the files in
this repository adaptations rather than copies:

- **Attribution** is required for every file marked `CC BY-*` or `CC BY-SA-*`.
  Naming the author and linking the source and the licence, as this file does,
  satisfies it.
- **Share-alike** applies to 35 of them, every file marked `CC BY-SA-*`.
  An adaptation of one of those must itself be offered under that licence or a
  compatible one. This is the reason the project cannot simply declare the
  whole tree MIT.
- **CC0 and public-domain** files carry no conditions. They are credited
  because crediting them is courteous, not because it is required.

If you are building a product rather than reading the code, the practical
answer is to replace the demo imagery with your own. It exists to make the
seeded dataset look like a real marketplace; nothing in the domain depends on
it.

The machine-readable originals are `CREDITS.json`, held beside the files
themselves, and this document is generated from them.
